# GazaOS

GazaOS is a custom ROM based on AOSP and Lunaris-AOSP, combining a lightweight **HyperOS-Hybrid** visual experience with cherry-picked customizations and stability fixes from across the Android community, including:

- **Lunaris-AOSP for core Android 16.2 base and framework changes**
- **LineageOS for vendor base, HALs, and device compatibility**
- **crDroid for various UI changes and customization features**
- **DerpFest and AxionAOSP for Modular QS and frame pacing**
- **Project Clover for GMS and theming improvements**
- **EvolutionX and PixelProps for Pixel features**
- **YAAP (Yet Another AOSP Project) for touch response and smoothness**
- **ViPER4AndroidFX and Sony Dolby Atmos for system audio**
- **Calyx Datura for built-in firewall controls**
- **And many more**

## Features

GazaOS brings a balanced mix of HyperOS-Hybrid polish, performance, and customization while keeping AOSP logic intact and builds lite for all devices:

- **Android 16.2 (Baklava) base**
- **HyperOS-Hybrid UI polish**: Rounded-square QS tiles with MIUI spring animations, smooth squircle icon masks & dialog radii, bento Settings & About Phone, HyperOS Lock Styles Studio, and lightweight HyperOS 4 media & clock typography
- **Lite & buildable by default**: Heavy add-on packages remain opt-in (`?= false`), `TARGET_LOW_END_BLUR=true`, and clean `speed-profile` dexopt
- **Customizable status bar, lockscreen, Gaza Lab, and Monet theming**
- **Performance optimizations and touch responsiveness tuning**
- **Free Palestine humanitarian solidarity identity**
